01 / Background & Focus

About Adarsh

Adarsh Anumula is a Software Engineer based in Hyderabad, India, combining a Computer Science and Engineering foundation from the Indian Institute of Technology Guwahati (IIT Guwahati) with hands-on production experience in enterprise web application development.

In the current role as an Associate Software Engineer at Proclink Consulting Services (July 2025–Present), engineering responsibilities center on designing and maintaining database-driven enterprise web applications using C#, ASP.NET Core 8, ASP.NET MVC, Razor, ADO.NET, Kendo UI MVC, and SQL Server. Daily engineering work involves implementing dynamic module configuration, role-based access control (RBAC), JWT-secured authentication flows, hierarchical main and sub-tab navigation systems, and multi-stage reviewer/approver workflows backed by optimized SQL Server stored procedures.

Alongside conventional enterprise backend engineering, ongoing project work focuses on Python backend services, Machine Learning, and Generative AI. This includes building asynchronous job-processing microservices with FastAPI, developing Retrieval-Augmented Generation (RAG) developer assistants and automated code review platforms using Large Language Models (LLMs), and training gradient-boosted classification pipelines (Scikit-learn, XGBoost, LightGBM) on complex tabular datasets.

Enterprise .NET Engineering
